# Linear Regression Model for Insurance

An interactive Streamlit application that estimates insurance charges from demographic, health, and financial details using a trained linear regression model.

**Live application:** [https://kavyajeergi-linearregressionmodelforinsurance-app-husgc3.streamlit.app](https://kavyajeergi-linearregressionmodelforinsurance-app-husgc3.streamlit.app)

## Overview

The application provides a simple web form for entering insurance-related information. It scales the entered values, sends them to a saved linear regression model, and displays the estimated insurance charges.

## Features

- Interactive user interface built with Streamlit
- Gender and smoker status selection
- Numeric inputs for claims, consultations, hospitalizations, expenditure, salary, and children
- Automatic encoding of categorical inputs
- Feature scaling using a saved `scaler.pkl`
- Insurance charge prediction using a saved `linear_regression_model.pkl`
- Predictions displayed in Indian rupees (₹)

## Input Features

| Feature | Description |
|---|---|
| Gender | Encoded as female = 1 and male = 0 |
| Claim Amount | Total claim amount |
| Past Consultations | Number of previous consultations |
| Past Hospitalizations | Number of previous hospitalizations |
| Hospital Expenditure | Existing hospital expenditure |
| Annual Salary | Applicant's annual salary |
| Number of Children | Number of children, from 0 to 5 |
| Smoker | Encoded as yes = 1 and no = 0 |

## Prediction Flow

1. The user enters the required details in the Streamlit interface.
2. Categorical values are converted to numeric form.
3. The input values are transformed with `scaler.pkl`.
4. The scaled values are passed to `linear_regression_model.pkl`.
5. The app shows the estimated insurance charges.

## Installation

Clone the repository:

```bash
git clone https://github.com/kavyajeergi/LinearRegressionModelForInsurance.git
cd LinearRegressionModelForInsurance
```

Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

On Windows, activate it with:

```bash
.venv\Scripts\activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## Run Locally

Start the Streamlit app:

```bash
streamlit run app.py
```

Streamlit will print a local URL, usually `http://localhost:8501`, which can be opened in a browser.
